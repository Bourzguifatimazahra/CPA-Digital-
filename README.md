## 🚀 Installation

### Prérequis
- Node.js >= 18.x
- npm ou yarn ou bun

### Étapes

```bash
# 1. Cloner le repository
git clone <repository-url>
cd CPA-Digital-

# 2. Installer les dépendances
npm install
# ou
yarn install
# ou
bun install

# 3. Lancer le serveur de développement
npm run dev
# ou
yarn dev
# ou
bun dev
```

L'application sera accessible sur `http://localhost:8080`
